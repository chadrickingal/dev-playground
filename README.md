# Dev Playground

A personal software engineering practice repository for building, experimenting, and improving programming and engineering skills through hands-on projects.

This repository contains small exercises, experiments, CLI applications, backend projects, database practice, and other projects created while learning software engineering.

## Purpose

The goal of this repository is to:

- Practice programming fundamentals
- Build projects through hands-on development
- Experiment with different technologies
- Practice Git and GitHub workflows
- Learn backend and database development
- Improve software engineering practices
- Document progress and lessons learned
